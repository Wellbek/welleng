# Subtract before you add

Apply when you sequence an addition, a refactor or a rewrite.

Remove complexity first, then build on the simpler base.
Leave the design slightly simpler and more capable than you found it.

- Remove dead code, redundant validators and stub references before construction.
- Get to the minimum before you invest in polish.
- Design for observed usage, not for speculative edge cases.
- Add no validator, parser or guard beyond what the requirement demands.
- Simplify prompts and instructions too, and delete a reference that has no new content.
