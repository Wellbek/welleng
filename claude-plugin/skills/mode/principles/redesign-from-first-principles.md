# Redesign from first principles

Apply when you integrate a new requirement into an existing design.

Do not bolt the change onto the existing design.
Redesign as if the requirement had been a foundational assumption from the start.

- Read every affected file and understand the current design.
- Ask what you would build if you wrote it from scratch with the new requirement.
- Carry the change through every reference: types, docs, examples, ADRs and rationale sections.
- Think through the whole redesign, then deliver it in increments.
