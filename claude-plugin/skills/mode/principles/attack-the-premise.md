# Attack the premise

Apply when two or more fixes that share one premise have failed the same check.

Suspect the premise, not the fixes.

- Write the premise down as the one sentence every failed fix assumed.
- Test it before the next fix.
  Find an observation that would come out differently if the premise were false, and make it.
  Look at how the failures are distributed, not only at how large they are.
- If the evidence contradicts the premise, look for what the failures share that it did not predict.

Do not start the next fix before the premise is written down and tested.
