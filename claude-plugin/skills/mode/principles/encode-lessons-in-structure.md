# Encode lessons in structure

Apply when you catch yourself writing the same instruction a second time, or you notice a recurring correction.

Encode the rule as a lint, a type, a test, a hook or a script instead of adding more text.
If the fix is structural, use only the structural fix, because the instruction is the symptom.

If the lesson needs judgment and cannot be encoded, make the instruction more prominent and add an example of the failure.
